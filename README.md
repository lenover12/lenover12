### Godot Multiplayer Minigame Hub (2026 - Current)
A Godot/GDScript multiplayer minigame framework built around reusable, inheritable base classes for common RPC networking patterns. Supports hot-swapping between different minigames within a shared hub, with peer-to-peer networking and one peer acting as the server host. Node authority is dynamically assigned according to the networking model required by each minigame, typically to the player who owns the relevant game state.

### WhatEatsWell – Nutrition Browser Extension (November 2024 - Current)
A browser extension that scrapes nutrition information from Woolworths.com.au product and recipe pages. Stores food choices locally, lets users build meals, and calculates nutrition totals by serving size.
